Ajouter une actualité (sans Facebook)

  1. Choisissez le fichier news.json actuel du site (celui de votre dossier GitHub).
  2. Remplissez l'actualité, puis cliquez sur « Ajouter et télécharger ».
  3. Sur GitHub : déposez le nouveau news.json (et les photos dans le dossier media) avec « Add file → Upload files ».
